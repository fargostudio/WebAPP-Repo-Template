# 🤖 Claude AI Directory

Questa directory contiene documentazione e istruzioni per Claude AI per lavorare efficacemente con questo template.

## Files

### `template-guide.md`
Guida completa e dettagliata per Claude AI con:
- Architettura e struttura completa del progetto
- Stack tecnologico con spiegazioni dettagliate
- Pattern e convenzioni da seguire
- Guide per sviluppo componenti e backend
- Workflow Git
- Common tasks e troubleshooting
- Quick reference

Questo file viene letto da Claude quando:
- Inizi un nuovo progetto basato su questo template
- Chiedi aiuto per aggiungere features
- Richiedi spiegazioni sull'architettura
- Hai bisogno di troubleshooting

## Scopo

Quando cloni questo repository per iniziare una nuova web app, Claude AI leggerà questi file per:

1. **Capire l'architettura** senza dover esplorare tutto il codice
2. **Seguire le convenzioni** stabilite nel template
3. **Proporre soluzioni** coerenti con il design system
4. **Aggiungere features** seguendo i pattern esistenti
5. **Risolvere problemi** comuni rapidamente

## Aggiornamenti

Se aggiungi nuovi pattern, convenzioni o features significative al template, aggiorna `template-guide.md` per assicurarti che Claude possa aiutarti efficacemente nei progetti futuri.

## Non Eliminare

⚠️ **Importante**: Non eliminare questa directory quando cloni il template per un nuovo progetto. Questi file sono essenziali per l'assistenza di Claude AI.
